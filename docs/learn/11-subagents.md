# 서브에이전트: 조수 여러 명 부리기

지금까지는 Claude를 비서 한 명처럼 썼어요. 그런데 사실 Claude는 **자기 밑에 조수들을 고용할 수 있는 팀장**이기도 합니다. 이 조수들을 **서브에이전트**라고 불러요.

이삿날을 떠올려 보세요. 한 사람이 주방, 거실, 침실을 혼자 다 싸려면 하루 종일 걸리지만, 세 명이 방 하나씩 맡으면 훨씬 빨리 끝나죠. 서브에이전트가 딱 그래요. 큰일을 조각으로 나눠 조수 여러 명에게 **동시에** 맡기고, 팀장 Claude가 결과를 모아 정리합니다.

사용법은 역시 말 한마디면 됩니다.

- "보고서 30개를 요약해야 해. **동시에 여러 명이 나눠서 하게 해줘**"
- "이 폴더 세 군데를 각각 다른 조수가 살펴보고 결과를 모아줘"

조수를 몇 명 쓸지, 일을 어떻게 나눌지는 Claude가 알아서 정해요. 우리는 "나눠서 해줘"라고만 하면 됩니다. 시간이 줄어드는 것은 물론, 조수마다 자기 일에만 집중하니 결과도 깔끔해져요.

재미있는 사실 하나 — 지금 보고 계신 **이 앱 자체가 그렇게 만들어졌어요**. 백엔드 담당, 화면 담당, 그리고 이 레슨을 쓴 콘텐츠 담당까지, 여러 에이전트가 각자 맡은 부분을 동시에 만들었답니다. 여러분도 곧 이런 팀을 부릴 수 있어요.

## 직접 해보기

여러 개를 한꺼번에 처리할 일(문서 여러 개 요약, 폴더 여러 개 살펴보기 등)을 하나 골라, "동시에 여러 명이 나눠서 하게 해줘"를 붙여 부탁해 보세요. 혼자 할 때와 속도를 비교해 보세요.
