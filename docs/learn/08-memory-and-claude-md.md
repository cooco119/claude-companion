# 메모리와 CLAUDE.md: 클로드의 수첩

단골 카페에 가면 "늘 드시던 걸로요?"라고 묻죠. 사장님이 내 취향을 **수첩에 적어두었기** 때문이에요. Claude에게도 그런 수첩이 있습니다. 바로 **CLAUDE.md**라는 메모 파일이에요.

Claude는 대화가 끝나면 그 내용을 잊어버려요. 그래서 새 대화를 시작할 때마다 "우리 파일은 이 폴더에 있고, 문서는 존댓말로 써 줘" 같은 설명을 반복해야 하죠. 하지만 수첩에 적어두면 달라집니다. Claude는 일을 시작할 때마다 이 수첩을 먼저 펼쳐 보기 때문에, **한 번 적어둔 내용은 다시 말하지 않아도** 돼요.

사용법은 놀랄 만큼 쉬워요. 대화 중에 그냥 이렇게 말하면 됩니다.

- "앞으로 요약은 항상 세 줄로 해 줘. **기억해줘**"
- "내 사진 원본은 절대 지우면 안 돼. 이거 기억해 둬"

"기억해줘"라고 하면 Claude가 알아서 수첩에 적어둡니다. 직접 파일을 열어 고칠 줄 몰라도 괜찮아요. 수첩은 폴더마다 따로 둘 수 있어서, 가계부 폴더에는 가계부 규칙을, 글쓰기 폴더에는 글쓰기 취향을 적어둘 수 있습니다.

비서에게 매일 아침 같은 설명을 반복하는 대신, 잘 정리된 인수인계 노트를 건네는 것 — 그게 CLAUDE.md예요.

## 직접 해보기

터미널에서 `claude`를 실행한 뒤 평소 원하던 규칙 하나를 말하고 "기억해줘"라고 해 보세요. 그다음 새 대화를 시작해 그 규칙을 기억하는지 확인해 보세요.
