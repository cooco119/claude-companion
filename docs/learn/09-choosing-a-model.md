# 모델 고르기: 일에 맞는 직원 찾기

Claude에는 여러 '모델'이 있어요. 모델은 쉽게 말해 **성향이 다른 직원들**입니다. 어떤 직원에게 맡길지 고르는 거예요.

- **Haiku 4.5** — 빠른 심부름꾼. 간단한 일을 즉시, 저렴하게 처리해요.
- **Sonnet 4.6** — 일 잘하는 보통 직원. 대부분의 일은 이 직원이면 충분해요.
- **Opus 4.8** — 베테랑. 까다롭고 긴 일을 꼼꼼하게 해냅니다.
- **Fable 5** — 혼자 맡겨두는 장기 프로젝트 전문가. 며칠 걸릴 일도 알아서 끌고 가요.

고르는 기준은 딱 두 가지 질문이에요. "**가는 길이 정해져 있나?**"(시키는 대로만 하면 되는 일인가, 아니면 스스로 길을 찾아야 하는 일인가)와 "**오래 걸리나?**"

| | 금방 끝나는 일 | 오래 걸리는 일 |
|---|---|---|
| **길이 정해져 있다** | Sonnet 4.6 (아주 단순 반복이면 Haiku 4.5) | Opus 4.8 |
| **길을 찾아야 한다** | Sonnet 4.6 (막히면 Opus 4.8) | Fable 5 |

영수증 정리처럼 단순한 일에 베테랑을 부르면 낭비고, 큰 프로젝트를 심부름꾼에게 맡기면 곤란하겠죠. 일의 크기에 맞는 사람을 부르는 게 요령이에요.

다 외울 필요는 없어요. 이 앱의 **🧭 컴패니언** 탭에서 요청문을 다듬으면, 그 일에 맞는 모델을 **자동으로 추천**해 줍니다.

추천받은 모델로 바꾸는 방법도 간단해요. 터미널의 Claude Code 안에서 `/model`이라고 입력하면 모델 목록이 나오는데, 거기서 원하는 모델을 고르면 됩니다.
