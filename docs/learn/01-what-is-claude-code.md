# 클로드 코드가 뭐예요?

**Claude Code**(클로드 코드)는 한마디로, **AI 비서가 내 컴퓨터에서 직접 일해주는 것**이에요.

평소 쓰는 챗봇(채팅으로 묻고 답하는 AI)은 "이렇게 해보세요"라고 말로만 알려줍니다. 요리로 비유하면, 전화로 레시피를 불러주는 친구예요. 반면 Claude Code는 **우리 집 부엌에 직접 와서 요리를 해주는 친구**입니다. 내 컴퓨터 안의 파일을 읽고, 새 파일을 만들고, 정리하고, 프로그램을 실행하는 것까지 직접 해줘요.

예를 들어 이렇게 부탁할 수 있어요.

- "바탕화면에 있는 사진들을 날짜별 폴더로 정리해줘"
- "이 영어 문서를 읽고 한국어로 요약한 파일을 만들어줘"
- "가계부 엑셀 파일에서 이번 달 지출 합계를 알려줘"

이름에 '코드(code)'가 들어 있어서 개발자 전용처럼 보이지만, 그렇지 않아요. 코드는 컴퓨터에게 일을 시키는 언어일 뿐이고, 그 어려운 부분은 Claude가 대신 해줍니다. 우리는 **한국어로 부탁만 하면** 됩니다.

물론 마음대로 움직이지는 않아요. 중요한 일을 하기 전에는 "이거 해도 될까요?"라고 꼭 물어봅니다. 이 이야기는 여섯 번째 레슨에서 자세히 다룰게요.

## 직접 해보기

터미널(글자로 명령하는 창)에 `claude`를 입력해 실행한 뒤, 이렇게 물어보세요. "지금 내가 있는 폴더에는 어떤 파일들이 있어?" — Claude가 내 컴퓨터를 직접 들여다보고 답해주는 걸 확인해 보세요.
