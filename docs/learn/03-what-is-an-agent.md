# agent(에이전트)가 뭐예요?

AI 이야기를 듣다 보면 **agent**(에이전트)라는 말이 자주 나와요. 어렵게 들리지만 뜻은 단순합니다. **시켜놓으면 알아서 단계를 밟아 일을 끝내는 비서**예요.

여행사 직원을 떠올려 보세요. "다음 달에 제주도 2박 3일 가고 싶어요"라고 한마디만 하면, 직원은 알아서 항공편을 찾고, 숙소를 비교하고, 일정표를 짜서 가져옵니다. 우리가 "이제 항공권 검색해", "이제 호텔 알아봐"라고 단계마다 일일이 지시하지 않아도요. 이렇게 **목표만 받으면 중간 단계를 스스로 계획하고 실행하는 것**이 바로 에이전트입니다.

Claude Code가 바로 이런 에이전트예요. 예를 들어 "이 폴더의 사진들을 연도별로 정리해줘"라고 하면, Claude는 속으로 이런 단계를 밟습니다.

1. 폴더 안에 어떤 파일이 있는지 살펴보고
2. 각 사진이 언제 찍힌 건지 확인하고
3. 연도별 폴더를 만들고
4. 사진을 옮긴 뒤
5. "이렇게 정리했어요"라고 결과를 보고합니다

중간에 문제가 생기면(예: 날짜 정보가 없는 사진 발견) 스스로 방법을 바꾸거나 우리에게 물어봐요. 그러니 우리가 할 일은 단계를 외우는 게 아니라, **원하는 결과를 분명하게 말해주는 것**입니다. 그 방법은 다음 레슨에서 배워요.
