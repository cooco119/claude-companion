# 스킬과 도구: 새 능력 꽂아주기

Claude는 처음부터 똑똑하지만, 우리 일에 딱 맞는 능력을 **추가로 꽂아줄** 수도 있어요. 크게 두 가지 방법이 있습니다.

첫째는 **스킬**(skill)이에요. 새로 온 직원에게 "우리 회사 보고서는 이 양식으로, 이 순서로 써 주세요"라고 **업무 매뉴얼을 미리 건네주는 것**과 같아요. 한 번 매뉴얼을 만들어 두면, 매번 길게 설명하지 않아도 `/보고서`처럼 짧은 명령어 하나로 그 일을 시킬 수 있습니다. 예를 들어 터미널에서 `/init`이라고 입력하면 "이 폴더를 파악해서 안내 문서를 만들어 줘"라는 매뉴얼이 실행돼요.

둘째는 **도구**(MCP)예요. 이건 매뉴얼이 아니라 **손에 새 연장을 쥐여주는 것**입니다. 망치만 있던 일꾼에게 드릴을 주면 할 수 있는 일이 늘어나듯, Claude에게 캘린더 도구를 연결하면 일정을 읽고, 메일 도구를 연결하면 메일을 검색할 수 있게 돼요.

정리하면 — 스킬은 "**어떻게** 일할지"를 알려주는 매뉴얼, 도구는 "**무엇을** 만질 수 있는지"를 늘려주는 연장이에요. 둘 다 직접 만들 필요는 없어요. "이런 스킬을 만들어 줘"라고 Claude에게 부탁하면 그것도 대신 만들어 줍니다.

## 직접 해보기

터미널에서 `claude`를 실행하고 `/`를 입력해 보세요. 사용할 수 있는 명령어(스킬) 목록이 나타납니다. 그중 하나를 골라 어떤 일을 하는지 Claude에게 물어보세요.
