# 첫 대화 해보기

이제 직접 말을 걸어 볼 차례예요. 긴장하지 않으셔도 됩니다. Claude와의 대화는 **처음 만난 친절한 직원에게 말을 거는 것**과 같아요. 어떤 질문이든 무시하거나 비웃지 않고, 모호하게 물어도 다시 친절하게 되물어 줍니다.

이 앱의 **💬 채팅** 탭을 열고, 무엇이든 물어보세요. 정답 같은 질문이 아니어도 괜찮아요.

- "너는 뭘 할 수 있어? 컴퓨터 잘 모르는 사람 기준으로 알려줘"
- "이번 주말에 아이랑 갈 만한 실내 활동 추천해줘"
- "이 문장을 더 정중한 말투로 바꿔줘: 내일까지 보내주세요"

몇 가지만 알아두면 더 편해요.

1. **한국어로 편하게** 쓰면 됩니다. 명령어나 특별한 형식은 필요 없어요.
2. 답이 오기까지 **수십 초 걸릴 수 있어요**. "생각 중…"이 떠 있으면 잠시 기다려 주세요. 사람도 좋은 답을 하려면 생각할 시간이 필요하잖아요.
3. 답이 마음에 안 들면 **이어서 다시 부탁**하세요. "더 짧게 해줘", "초등학생도 알아듣게 다시 설명해줘"처럼요. 대화는 이어지고, 자동으로 저장됩니다.
4. 모르는 단어가 나오면 그 자리에서 물어보세요. "방금 말한 ○○가 뭐야?" — 이게 가장 빠른 공부법이에요.

## 직접 해보기

채팅 탭에서 새 채팅을 열고, 요즘 궁금했던 것 아무거나 하나를 물어보세요. 답이 오면 "더 쉽게 설명해줘"라고 한 번 더 부탁해 보세요. 대화가 이어지는 느낌을 직접 경험하는 게 목표입니다.
