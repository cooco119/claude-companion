# 잘 시키는 법

같은 비서라도 부탁을 어떻게 하느냐에 따라 결과가 크게 달라져요. 비결은 세 가지만 기억하면 됩니다. **목표, 맥락, 완료 기준.**

이사짐 도우미에게 "정리 좀 해주세요"라고만 하면 어떻게 될까요? 어디를, 어떤 기준으로, 어디까지 해야 하는지 몰라 우왕좌왕하겠죠. 대신 "주방 박스를 풀어서(목표), 자주 쓰는 그릇은 손 닿는 칸에 넣어 주세요. 우리 집은 아이가 있어서 칼은 위 칸으로요(맥락). 박스가 다 비고 바닥에 아무것도 없으면 끝이에요(완료 기준)"라고 하면 한 번에 원하는 결과가 나옵니다. Claude에게도 똑같아요.

1. **목표** — 무엇을 원하는지 한 문장으로. "여행 사진 정리해줘" → "사진 폴더의 파일들을 연도-월 폴더로 나눠줘"
2. **맥락** — 알아야 할 배경. "스마트폰에서 옮긴 사진이라 파일 이름이 제각각이야", "원본은 지우면 안 돼"
3. **완료 기준** — 어떤 상태면 끝인지. "정리 후 각 폴더에 사진이 몇 장씩 들어갔는지 표로 보여줘"

다 갖춰 말하기 어려우면 솔직하게 "내가 뭘 더 알려줘야 할지 먼저 물어봐 줘"라고 해도 좋아요. 그리고 이 앱의 **🧭 컴패니언** 탭에는 보내기 전 요청문을 같이 다듬어 주는 기능이 있으니, 막막할 때 활용해 보세요.
