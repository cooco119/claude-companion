# 파일과 폴더 다루기

Claude Code의 진짜 힘은 **내 컴퓨터의 파일을 직접 다룰 수 있다**는 점이에요. 파일과 폴더는 서류와 서류함이라고 생각하면 됩니다. Claude는 서류함을 열어 보고, 서류를 분류하고, 새 서류를 만들어 주는 **부지런한 사무 보조**인 셈이죠.

한 가지 중요한 습관이 있어요. Claude는 **지금 열려 있는 폴더 안에서** 일합니다. 터미널에서 `cd 폴더이름`(체인지 디렉터리 — "이 폴더로 이동"이라는 뜻)으로 작업할 폴더에 들어간 뒤 `claude`를 실행하세요. 비서를 정리할 방 안으로 데려가서 일을 시작하는 것과 같아요.

실생활에서 이런 부탁을 할 수 있어요.

- **정리**: "다운로드 폴더에서 PDF는 '문서' 폴더로, 사진은 '사진' 폴더로 옮겨줘"
- **변환**: "이 한글 메모 파일들을 하나의 PDF로 합쳐줘", "이 표를 엑셀에서 읽을 수 있는 파일로 바꿔줘"
- **찾기**: "이 폴더 어딘가에 '계약'이라는 단어가 들어간 문서가 있을 텐데 찾아줘"
- **요약**: "이 회의록 파일을 읽고 결정된 사항만 뽑아서 새 파일로 정리해줘"

걱정되는 일(예: 파일 삭제)을 시킬 때는 "지우지 말고 '백업' 폴더로 옮겨줘"처럼 안전한 방식을 함께 말해주면 좋아요. 처음에는 복사본을 만들어 둔 연습용 폴더에서 시작하는 것도 좋은 방법입니다.

## 직접 해보기

바탕화면에 '클로드연습'이라는 폴더를 만들고 아무 파일이나 몇 개 복사해 넣으세요. 터미널에서 그 폴더로 이동해 `claude`를 실행한 뒤, "이 폴더의 파일들을 종류별 폴더로 정리해줘"라고 부탁해 보세요.
