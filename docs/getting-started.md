# 처음부터 끝까지 따라하는 설치 가이드

이 문서는 **Claude Code**(클로드 코드 — 내 컴퓨터에서 직접 일해주는 AI 비서)를 설치하고 로그인하는 과정을, 컴퓨터를 잘 모르는 분도 그대로 따라 할 수 있게 손으로 짚어가며 안내합니다. 천천히 하셔도 됩니다. 보통 10~15분이면 끝나요.

## 0. 터미널이 뭐예요?

**터미널**(terminal)은 마우스 클릭 대신 **글자로 컴퓨터에 명령을 내리는 창**이에요. 까만(또는 하얀) 화면에 글자만 있어서 낯설지만, 사실 하는 일은 단순해요. "이거 해줘"라고 한 줄 적고 Enter(엔터)를 누르면 컴퓨터가 그 일을 합니다. 식당에서 점원에게 말로 주문하는 대신, 주문서에 또박또박 적어서 건네는 것과 같아요.

이 가이드에서 "터미널에 입력하세요"라고 하면, 아래에 나오는 회색 상자 속 글자를 **복사해서 터미널 창에 붙여넣고 Enter를 누르면** 됩니다.

### 터미널 여는 법

**macOS(맥)를 쓰신다면**
1. 키보드에서 `command(⌘)` 키와 스페이스바를 동시에 누르세요. 검색창(Spotlight)이 뜹니다.
2. `터미널` 또는 `terminal` 이라고 입력하고 Enter를 누르세요.
3. 하얀(또는 까만) 창이 하나 열리면 성공입니다. (창 위쪽에 "터미널" 또는 사용자 이름이 보이고, 커서가 깜빡이고 있으면 맞아요.)

**Windows(윈도우)를 쓰신다면**
1. 키보드의 윈도우 키(⊞)를 누르세요.
2. `PowerShell`(파워셸) 이라고 입력하고 Enter를 누르세요.
3. 파란(또는 까만) 창이 열리면 성공입니다. 이 가이드에서 "터미널"이라고 하면 이 PowerShell 창을 뜻해요. (창 안에 `PS C:\Users\...>` 처럼 PS로 시작하는 글자가 보이면 맞아요.)

## 1. Node.js 설치하기

**Node.js**(노드제이에스)는 나중에 설치할 **클로드 컴패니언 앱**이 돌아가는 데 필요한 바탕 프로그램이에요. 전자제품을 쓰려면 먼저 콘센트(전기)가 있어야 하듯, 이 앱을 쓰려면 먼저 Node.js가 있어야 합니다. (Claude Code 자체는 Node.js 없이도 설치되지만, 어차피 앱에 필요하니 지금 같이 설치해 두는 게 편해요.)

1. 브라우저에서 [https://nodejs.org](https://nodejs.org) 를 여세요.
2. 초록색 큰 버튼 중 **LTS**(엘티에스 — '오래 안정적으로 지원되는 버전'이라는 뜻)라고 쓰인 쪽을 클릭해 내려받으세요.
3. 내려받은 파일을 더블클릭하고, 설치 화면에서 계속 "다음/Next"를 눌러 기본 설정 그대로 설치하세요.

설치가 끝났으면 **터미널 창을 한 번 닫았다가 다시 열고**, 아래를 입력해 확인해 보세요.

```bash
node -v
```

`v22.16.0` 처럼 v로 시작하는 숫자가 나오면 성공입니다. "command not found(명령을 찾을 수 없음)" 비슷한 말이 나오면 터미널을 닫았다 다시 열어 보시고, 그래도 안 되면 컴퓨터를 재시작한 뒤 다시 시도해 보세요.

## 2. Claude Code 설치하기

이제 Claude Code를 설치할 차례예요. 운영체제에 맞는 **한 줄**을 터미널에 붙여넣고 Enter를 누르면 끝입니다. "인터넷에서 설치 프로그램을 받아와서 바로 실행해줘"라는 뜻이에요.

**macOS(맥)** — 터미널에:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

**Windows** — PowerShell(파워셸) 창에:

```powershell
irm https://claude.ai/install.ps1 | iex
```

- 글자들이 주르륵 올라가다가 멈추면 끝난 거예요. 1~2분 걸릴 수 있어요.
- 설치가 끝나면 **터미널 창을 닫았다가 다시 열고** `claude --version` 을 입력해 보세요. 숫자(버전)가 나오면 성공입니다.
- 이렇게 설치하면 앞으로 **새 버전이 나올 때마다 자동으로 업데이트**돼서 신경 쓸 게 없어요.

> **Windows에서 `irm` 명령이 인식되지 않는다는 에러가 나면**, 지금 열린 창이 PowerShell이 아니라 CMD(명령 프롬프트)인 거예요. 창의 맨 앞 글자를 보세요 — `PS C:\` 로 시작하면 PowerShell, 그냥 `C:\` 로 시작하면 CMD입니다. 시작 메뉴에서 "PowerShell"을 검색해 새로 열고 다시 시도해 주세요.

> 예전 안내(`npm install -g @anthropic-ai/claude-code`)를 본 적이 있다면, 지금은 위의 방법이 공식 권장이에요. 둘 다 동작하지만 위 방법이 더 간단하고 자동 업데이트까지 됩니다.

## 3. Claude 계정 만들기 (가입)

Claude Code를 쓰려면 Anthropic(앤트로픽 — Claude를 만든 회사)의 Claude 계정이 필요해요. **이미 claude.ai 에서 Claude를 써 본 적이 있다면 이 단계는 건너뛰세요.**

1. 브라우저에서 [https://claude.ai](https://claude.ai) 를 엽니다.
2. **"Continue with Google"**(구글 계정으로 계속) 또는 이메일 주소 입력 중 편한 쪽을 고르세요. 이메일을 입력하면 받은편지함으로 로그인 링크가 와요 — 메일을 열고 버튼을 누르면 가입이 끝납니다. 따로 외울 비밀번호가 없어서 편해요.
   - [스크린샷: claude.ai 첫 화면의 가입/로그인 선택지]
3. 가입 직후에는 무료 요금제 상태입니다. **Claude Code를 제대로 쓰려면 유료 구독(Pro 또는 Max)이 필요해요.** 화면의 업그레이드 안내를 따라 Pro 구독을 시작하세요. 가족이 이미 구독 중인 계정을 함께 쓰기로 했다면, 그 계정으로 로그인만 하면 됩니다.

## 4. Claude 실행하고 로그인하기

설치가 끝났으면 터미널에 이렇게 입력하세요.

```bash
claude
```

처음 실행하면 로그인을 안내해 줍니다. 흐름은 이렇습니다.

1. 터미널에 로그인 방법을 고르는 화면이 나옵니다. 화살표 키로 선택하고 Enter를 누르세요. Claude 구독(Pro/Max) 계정이 있다면 **Claude account with subscription** 쪽을 고르면 됩니다.
2. 자동으로 **브라우저 창이 열리면서** Anthropic(앤트로픽 — Claude를 만든 회사) 로그인 페이지가 나타납니다. 평소 Claude를 쓰던 계정(이메일)으로 로그인하세요.
3. "승인/Authorize" 버튼을 누르면, 화면에 코드가 보이거나 자동으로 연결이 완료됩니다. 코드가 보이면 복사해서 터미널에 붙여넣고 Enter를 누르세요.
4. 터미널에 환영 메시지가 나오면 로그인 성공입니다. 🎉

로그인은 한 번만 하면 컴퓨터가 기억합니다. 다음부터는 `claude`만 입력하면 바로 대화할 수 있어요.

## 5. 잘 됐는지 확인하기

터미널의 Claude 화면에서 가볍게 인사를 건네 보세요.

```
안녕! 너는 무슨 일을 할 수 있니?
```

답이 돌아오면 모든 준비가 끝난 것입니다. 끝내고 싶을 때는 `/exit` 라고 입력하고 Enter를 누르면 돼요. (`Ctrl + C` 로 끝내려면 **빠르게 두 번** 눌러야 합니다. 한 번 누르면 지금 하던 입력만 취소되고, 화면에 "Press Ctrl-C again to exit"라고 안내가 떠요 — 고장난 게 아니니 놀라지 마세요.)
